# Квиз монтажёру

Инструмент вопросов с вариантами (AskUserQuestion): до 4 вопросов за окно, 2–4 варианта, «Другое» есть всегда, рекомендуемый — первым с пометкой (Recommended). Показывай через 1–2 мин после старта, пока в фоне идёт медленный проход. Не спрашивай то, что монтажёр уже сказал или что лежит файлом. «Сделай хорошо» — без вопросов: базовый, без рилсов и тизера.

| Окно | Вопрос | Варианты |
|---|---|---|
| 1 | Монтаж | Базовый · Смысловой · Только v00 |
| 1 | Что ещё (множественный выбор) | Рилсы · Тизер из хайлайтов · Плашки имён · Субтитры к выпуску |
| 1 | Айдентика | Есть файлы в папке · Пришлю · Нет → стиль Apple |
| 1 | Прошлый выпуск этого клиента | Есть (укажу папку) · Новый клиент |
| 2 | Длина (если смысловой) | Сколько интересно · Вдвое короче · Своё число |
| 2 | Рилсов (если рилсы) | 10–15 · 5 · Своё число |
| 2 | Музыка тизера (если тизер) | Дам файл · Сгенерировать · Без музыки |
| 2 | Заставка · Сноски на Meta/иноагентов · Мат | по ситуации |

Рекомендации подсказывает исследование: курс → «по сценарию», 2 ч подкаста → «рилсы 10–15». Ответы пиши в `project.json` и `client.md`.
