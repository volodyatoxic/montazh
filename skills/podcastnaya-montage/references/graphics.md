# Графика и моушн

## Общее
- Весь моушн — поверх, на своих дорожках. Картинку камер не трогаем.
- Плашки — MOV с альфой (ProRes 4444 / QuickTime Animation). Полноэкранное — непрозрачное.
- Дорожки: V1 камеры · V2 правки кадра · V3+ графика · A1 звук камер (выкл) · A2…An мики · MUSIC · SFX. Звук раскладываем, не сводим.
- Айдентика клиента — из квиза. Платные шрифты бренда → похожие OFL, сказать об этом.
- Нет айдентики → стиль Apple: плавно, шрифт **Inter**.
- Движок: HTML-сцена с `renderFrame(t)` → headless Chrome покадрово с прозрачным фоном → MOV с альфой, SFX отдельным WAV.
- До показа: ревизор вёрстки (текст не обрезан, не вылез, не налез), стоп-кадры (не на лице, нет чёрного прямоугольника вместо альфы), длительность = план.
- «Стекло» Apple с размытием подложки оверлеем не сделать: полупрозрачная плашка без размытия или размытие руками в Resolve.

## Профили движения
| Жанр | Характер |
|---|---|
| Подкаст | спокойно, минимально, не отвлекает от людей; мягкий вход, без отскоков, уход обратным движением |
| Курс | уверенно, показывает действие: пункты под речь, цвет = смысл, сплит 1/3 + 2/3, сдвиг видео |
| Эксплейнер | плотно, событие на каждое слово |

Общие правила: проявление 0→100% за ~0,3 с; easeOutCubic на входе, easeInCubic на уходе, без баунса; ничего не возникает из воздуха; успеть прочитать (≥ 1 с, ~0,3 с на слово); связанное двигается группой; растр не увеличиваем; без противофазы; без заголовков-слайдов.

## Подкаст: плашки имён (только по просьбе)
- Не выдумываем. Показываем стоп-кадр спикера, предлагаем имя, монтажёр подтверждает. Регалии необязательны.
- Написание — только из текста (слова монтажёра, документ). Распознавание коверкает фамилии.
- Когда: первое заметное включение спикера, ~4–5 с, на его крупном плане. Где: нижняя треть, со стороны свободного места, не на лице.

## Шаблоны подкаста
Плашка имени · сноска на упоминание (Meta, иноагенты) · заставка (если дали) · тизер.
