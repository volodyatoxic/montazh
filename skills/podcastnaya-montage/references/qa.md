# Контроль качества

Сначала дешёвое. Всё до распознавания — меньше минуты на час материала. Вход — **звук таймлайна, отрендеренный только звуком** (проверяем то, что реально стоит в Resolve, с ручными правками человека).

| Уровень | Проверка | Как |
|---|---|---|
| 1. Огибающая (мс на стык) | обрыв слова на склейке | по исходнику: энергия у точки выхода выше порога речи и речь продолжается после неё (и так же для входа) |
| | щелчок | скачок сэмплов на стыке |
| | полвдоха | шумовая полоса вдоха начинается до реза и обрывается |
| 2. Структура | дыры, наложения, длина = план, A1 выключена, все дорожки на месте | клипы через API |
| | синхра | у каждого клипа смещение видео/звука = модели ±1 кадр |
| | короткие планы, строб, заморозки в использованных кусках | из исследования |
| 3. Сверка с разметкой | каждый красный маркер вырезан или объяснён; каждый синий получил зелёный или жёлтый «НЕ СДЕЛАНО» | база |
| 4. Только по флагам 1–2 | распознавание окна ±1,5 с (CTC буквально + Whisper) | секунды на окно |
| 5. Фоном, по желанию | расшифровка всей версии против плана | минуты |

Итог — таблица OK/⚠ в отчёте, каждый ⚠ — жёлтый маркер. Видео для проверки не рендерим.
