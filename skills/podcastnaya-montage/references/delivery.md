# Сдача

## Рендер (только по команде)
- Пресет `chapters purple`: MP4 H.264 1080p, главы из фиолетовых маркеров. Нет в Resolve → `resolve.ImportRenderPreset("$SKILL/presets/chapters purple.xml")`.
- Куда: `<проект>/renders/` (создать, если нет). Имя с версией: `<проект> v03.mp4` — по нему видно, к какой версии относятся таймкоды правок клиента.
- Перед рендером: Resolve свободен, нужный таймлайн, A1 выключена, `DeleteAllRenderJobs`, `ExportVideo: True`. После — ffprobe: длительность = таймлайну, есть видео, главы на месте (`ffprobe -show_chapters`).
- Перерендер — во временное имя, потом заменить. Рендеры клиента не удалять самому.

## Главы
- Всегда. Фиолетовые маркеры на каждой версии выпуска, имя маркера = название главы, первый — на 0:00 («Вступление»).
- Правила YouTube: первая с 00:00, не меньше 3, каждая ≥ 10 с.

## Тексты к выпуску — `renders/<проект> — тексты vNN.md`
- 5–10 названий с разных углов (польза, интрига, цитата, имя гостя).
- Описание короткое (2–3 предложения) и полное.
- Главы `00:00 Вступление` … — таймкоды по этой версии.
- Ссылки на гостя (из слов монтажёра/файлов).
- Стиль — по профилю клиента.

## markers.json — рядом с каждым рендером (`<имя рендера>.markers.json`)
Для сервиса просмотра (скилл `video-review`).
```json
{"render": "Podcast Ivanov v03.mp4", "timeline": "v03 · правки клиента 2", "fps": 50,
 "markers": [{"t": 842.4, "dur": 0.0, "color": "Green", "name": "П2.3 вырез",
              "note": "Клиент: «уберите про отпуск» → вырезали 14:02–14:19 (17 с)", "id": "r2.3"}]}
```
