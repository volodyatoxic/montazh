# Учимся на правках человека

## Снимки таймлайнов
- Дважды на каждую версию: «как сдал» (сразу после сборки) и «как оставил человек» (в начале следующего круга).
- Снимок: клипы (дорожка, исходник, in/out, позиция), свойства (Pan/Zoom/кроп), маркеры, включённые дорожки → `00_db/snapshots/vNN.<delivered|human>.json`. Плюс `tl.Export(path, resolve.EXPORT_DRT)` как бэкап.
- Разница: подрезал голову на N с в M стыках, удалил кусок, сменил план, вернул вырезанное. Fairlight через API не видно.

## Уроки
- Вывод → `lessons.jsonl` с доказательствами: «в 12 из 15 стыков ты срезал воздух до 0,05 с → наш запас 0,12 велик».
- Правило — только при повторе (≥ 3 случаев) или после подтверждения человеком. Не больше 1–2 вопросов «почему» за круг.
- Вкус конкретного клиента → `client.md`, не в общие правила.
- Подтверждённое переносится в скилл: правка `references/` или скрипта + строка в `CHANGELOG.md`. Репозиторий публичный — **без имён клиентов и цитат**.

## Профиль клиента — `_agent/00_db/client.md`
Правила, айдентика, стиль субтитров, мат, сноски, что отвергали. На старте спроси «есть прошлый выпуск этого клиента?» — если есть, скопируй профиль оттуда.
