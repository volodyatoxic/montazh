# Риски публикации

На исследовании прогони расшифровку по `rules/publish-risks.json` (ищем по формам слова). Каждое попадание — жёлтый маркер: цитата, категория, предложенный текст сноски.

| Категория | Примеры | Что предлагаем |
|---|---|---|
| Продукты Meta | Instagram, Facebook, Meta, Threads | сноска «*принадлежит Meta, признана экстремистской и запрещена в РФ» |
| Иноагенты, запрещённые организации | имена и названия из реестров | сноска; список меняется — сверяй с актуальным реестром, если есть интернет, иначе «проверь» |
| Мат | — | по профилю клиента: вырезать / запикать / оставить |
| Прочее спорное | наркотики, призывы | жёлтый, решает человек |

- Сноска — шаблон графики: мелкий текст внизу на время упоминания + ~2 с.
- Ставить сноски самому или только маркеры — вопрос квиза, ответ — в `client.md`.
- Расшифровка может не расслышать слово — это помощь, не юридическая проверка.
- Новые триггеры дописывай в `rules/publish-risks.json`.
