- Агенту после обновления: запусти `tools/install.py` (новые зависимости: pillow, Inter).

## 0.1.1 — 30.10.2026, первая боевая съёмка (подкаст, ATEM Mini Pro ISO + Zoom P8)
Написаны недостающие скрипты, все обкатаны на материале ATEM Mini Pro ISO + Zoom P8:
- `atem_parse.py` — разбор `.drp`: нарезка оператора, короткие склейки, строб, метки PiP.
- `transcribe.py` — микс P8 → mlx-whisper → сегменты и слова, говорящий по энергии микрофонов, микрофон ↔ камера по нарезке оператора.
- `risks.py` — риски публикации по словарю `rules/publish-risks.json`.
- `sync.py` — синхра P8 ↔ камеры (GCC-PHAT), двухпроходная: грубый поиск, потом точный.
- `resolve_v00.py` — v00 из импортированного проекта ATEM + дорожки P8, звук ATEM выключен.
- `resolve_v01.py` — сборка версии по плану резов, разбавление длинных планов реакцией слушателя, маркеры.
- `qa.py` — структура, синхра, сверка с разметкой, стыки по отрендеренному звуку.

Найдено в `scan.py` (не исправлено):
- без папки `source/` одна съёмка разбивается на несколько по подпапкам → неверный сценарий (дал S4+S2 вместо S1) и ложные тревоги «нет P8», «нет .drp»;
- папка только со звуком ATEM (`atem_audio`) выпадает из отчёта: роль не входит в фильтр `av_shoots`;
- чёрная камера не ловится: CAM 4 писала чёрный кадр весь час, а в отчёте её нет.

Грабли Resolve дописаны в `references/resolve.md`.
