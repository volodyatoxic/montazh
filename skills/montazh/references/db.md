# Агентская папка и база

Всё агентское — в `<проект>/_agent/`. Удалили папку — как будто агент не работал, кроме проекта в Resolve (он записан в `README.md` и `timelines.jsonl`, удаляется по `cleanup` после подтверждения) и рендеров в `renders/`.

```
_agent/
  README.md                 что это, как удалить, какой проект Resolve наш
  00_db/                    память агента
    brief.md                сводка на один экран — читать первой в каждой сессии
    project.json            паспорт: тип, сценарий, длительность, уровень заказа
    files.jsonl             каждый файл: путь, размер, ffprobe, роль
    recordings.json         какие файлы составляют одну запись
    speakers.json           спикер ↔ мик ↔ камера, имена (написание — только из текста)
    sync.json               смещение и дрейф по каждой паре
    transcript/             *.segments.jsonl, *.words.jsonl (таймкод + мик)
    topics.jsonl            темы, главы, мысли, цитаты
    highlights.jsonl        кандидаты в тизер и рилсы с причинами
    requests.jsonl          правки: кто, когда, цитата, продукт, что сделали
    decisions.jsonl         решения агента с причиной
    timelines.jsonl         всё, что агент создал в Resolve
    snapshots/              состояния таймлайнов «как сдал» / «как оставил человек»
    lessons.jsonl           выводы из правок человека
    alerts.jsonl            тревоги
    client.md               профиль клиента
    usage.jsonl             отметки учёта
    journal.jsonl           все действия по порядку, сквозной номер seq
  01_intake/                REPORT.md, контакт-листы, уровни
  02_sync/
  03_transcript/            wav 16k, сырые расшифровки
  04_edit/v01/ v02/ …       план, монтажный лист, проверки стыков
  05_gfx/
  06_reels/
  07_qa/                    звук для проверки, отчёты проверок
  cache/                    можно удалить, пересчитается
```

## Правила
- JSON/JSONL текстом: читаешь и ищешь grep'ом. JSONL пишется только дозаписью.
- У каждой записи: `ts` (время), `src` (откуда: файл, таймкод, слова монтажёра, маркер), для правок и решений — `version`.
- Журнал ведут скрипты через `common.journal()`, не руками. Свои ручные шаги тоже пиши через `python3 "$SKILL/scripts/common.py" log <проект> "<что сделал>"`.
- `brief.md` пересобирается после каждого этапа: что за проект, где остановились, что дальше, открытые вопросы.
- Тяжёлое (wav, кадры) — в папки этапов, в `00_db/` только данные.
