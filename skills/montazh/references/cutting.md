# Монтаж: что резать и как

## Уровни (прайс: базовый 6 000 ₽/ч, смысловой 28 000 ₽/ч)

### Базовый — подчистить, смысл не трогать
- Голова: старт за 0,3–0,5 с до приветствия («Здравствуйте», «Всем привет»), после «запись идёт / можем начинать». Несколько дублей приветствия — последний чистый.
- Хвост: после прощания («Спасибо, пока»). Болтовня за кадром — прочь.
- Заставка, если дали файл, — в начало.
- Очевидное: техостановки (метки оператора, «давай заново», возня с микрофоном, «сколько у нас времени»), явные запинки (обрывок слова + повтор, слово дважды), долгое общее молчание.
- Порядок и содержание не трогаем. Камеры — нарезка оператора, правим только вспышки и строб.
- Режем только уверенное, сомнительное — жёлтым.
- **Паузы в разговоре не как в курсе:** режем только общее молчание всех миков от ~2,5 с, оставляем ~0,6 с. Пауза перед ответом — живость.

### Смысловой — сделать интересно
- Опора — исследование: темы, мысли, цитаты уже в базе.
- Режем скучное: разгоны, повторы мысли, уходы в сторону, слабые блоки. У каждого — красный маркер с причиной («повтор мысли из 14:20»).
- Всё вырезанное по смыслу — в таймлайн «Вырезанное vNN» по порядку, с причинами. Вернуть кусок — минута.
- Блоки не переставляем (только по запросу), рекомендации — строкой в отчёте.
- Целевая длина — из квиза.
- Тизер в начале: 3–5 фрагментов, 30–60 с, каждый — законченная мысль, по нарастанию, сильнейшее — да, но панчлайн обрываем до развязки; дальше заставка, потом выпуск. Музыку для тизера спрашиваем всегда (файл / генерация / без).
- Хайлайты: по смыслу (сабагент: сильные утверждения, панчлайны, цифры, спор) + по звуку (смех, наложение голосов, всплески громкости/темпа). Сначала список квизом, потом сборка.
- Деление на выпуски — только по просьбе.

### Курс (логика из podcast-montage, переносится следом)
Говорящая голова по суфлёру: последний чистый дубль, сверка со сценарием, детектор запинок R1–R9 (CTC), паузы режем плотно, общий план основной. Сценарий берём из папки/слов монтажёра, нет — спрашиваем, нет вовсе — предлагаем структуру по расшифровке.

## Как резать без лишних звуков
1. Рез только в тишине (энергия ниже пола шума +9 дБ, ≥ 0,12 с). Пол шума — 20-й перцентиль энергии.
2. Начало куска: ≤ 0,12 с тишины перед словом. Конец: ≤ 0,10–0,25 с после.
3. Несколько миков: «тишина» = все мики ниже своего фона +12 дБ; говорящий = чей мик громче.
4. Вдох либо целиком, либо нет.
5. Тишины нет — режь по границе слова, жёлтый маркер.
6. Whisper «причёсывает» запинки и склеивает фальстарт с повтором — края кусков проверяй побуквенной моделью (wav2vec2 CTC).

## Камеры в подкасте
- Длинные планы 10–20 с — норма, ракурсы меняем ради динамики.
- Общий план нечасто: когда за 2–3 с активны два мика и больше (перебивки, смех, спор) или план говорящего непригоден.
- Дольше ~25–30 с на одном ракурсе — сменить (другой ракурс говорящего или реакция слушателя).
- Джамп-кат после выреза прячем ракурсом слушателя или другим ракурсом говорящего; общий — если иначе никак.
- Хорошую нарезку оператора не переделываем. Правила применяются: без ATEM (S4), на стыках, в рилсах/тизере, как мягкая проверка оператора.
- В курсе наоборот: общий план основной.

## Короткие и строб-склейки (по логу ATEM и мика)
| Что | Признак | Действие |
|---|---|---|
| вспышка | план < 0,5 с | почти наверняка не та кнопка: предложить продлить предыдущий план, голубой |
| паразитная | 0,5–1,5 с, человек в кадре молчит | голубой «паразитная склейка?» |
| оправданная | 0,5–1,5 с, человек в кадре начал говорить | не трогать |
| строб | ≥ 3 переключений за 4 с | голубой |
| не тот план | камера на молчащем долго, говорит другой, не похоже на реакцию | жёлтый (реакции бывают нарочно) |
⚠️ Пороги калибруем на реальных съёмках и дописываем сюда.

## Мат, оговорки, метки оператора
- Мат — по профилю клиента: вырезать (красный), запикать или оставить; по умолчанию жёлтый.
- Удары по микрофону — не резать, пометить (звук — за монтажёром).
- Мета-реплики («надо как-то подытожить») — режем, только если явно не часть разговора; иначе жёлтый.
